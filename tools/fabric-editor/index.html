    KFPS Vinyl Editor Guide

    What This Editor Does

    This is a native-shape layer editor for Forza vinyls. Build artwork by hand, clean up generated work, or continue an existing JSON. It edits game shapes rather than image pixels.

    The editor supports up to 3000 layers and keeps demanding projects responsive with its hybrid renderer.

    First Project Workflow

    1. Choose Open JSON, or add a shape to begin on a blank canvas.
    2. Choose Save early. A project keeps editable layers, groups, guides, names, locks, and the reference image.
    3. Add a Reference if you want to trace or sample the original artwork.
    4. Select, transform, recolor, add, duplicate, group, mask, and reorder native layers.
    5. Review Export Check, then choose Export JSON.
    6. In KFPS Outputs, choose Editor exports and import the exported JSON normally.

    Tools On The Left

    • Select: click, box-select, move, resize, skew, rotate, align, distribute, and edit exact values.
    • Shapes: search and place native shapes, or replace a selected shape once.
    • Text: turn typed text into editable native Forza letter layers.
    • Pixel: detect a deliberate pixel grid and merge same-color cells into efficient rectangles.
    • Dropper: pick color from a vinyl layer or the reference image.
    • Guides: draw non-exported guides and configure the snapping grid.
    • Reference / Move Ref: add and adjust tracing artwork independently of vinyl layers.
    • Mask: toggle selected layers as cutouts that affect layers below them.

    Shape Library

    • Use the category dropdown to browse shapes in an FH6-like order.
    • Use search for shape names, numbers, families, or type codes.
    • Click a tile to place that shape in the current viewport.
    • Use the toolbar Place setting to add at the top, insert above/below a selected layer, or replace once.
    • Duplicate also follows Place mode, so duplicated layers can be inserted above or below the current selection instead of always going to the top.
    • Replace Once keeps position, color, alpha, group, lock, and layer order, then returns to At Top.
    • Use the favorite button on a tile to keep common shapes near the top.
    • New shapes use the active color unless live reference sampling is enabled.
    • Gradient Shapes preview with their bundled fade masks instead of flat solid fills.
    • Reuse last font size helps repeated font characters stay consistent.

    Layers, Groups, Locking, And Visibility

    • Top layer rows draw over lower layer rows.
    • Forward and Back move one step. To Front and To Back move selected layers to an edge.
    • Use Group for editor-only organization. Groups help select, hide, or lock related layers without changing export structure.
    • Rename Layer and Rename Group make dense projects easier to scan without changing game resources.
    • Hide Group hides grouped layers while editing. Hidden vinyl layers still export, and Export Check warns about them.
    • Lock Group prevents accidental edits to grouped layers.
    • Drag the divider below Layers to resize the list. Collapse gives the active inspector nearly the full dock.

    Color And Reference Sampling

    • Properties edits the active color and alpha alongside exact transform controls.
    • When multiple layers are selected, color edits apply to every selected unlocked layer.
    • Saved colors work like a small paint palette for colors you reuse often.
    • Clicking a saved color applies it to the current selection. Locked layers are skipped.
    • The reference image is saved with the project and recovery copy, but never exported into game JSON.
    • Sample Reference Under Selection recolors selected layers from the artwork beneath them.
    • Live color from reference updates color while you move or resize a shape over the artwork.
    • Dominant color is usually better for flat decals. Average color is useful for softer shaded regions.

    Guides, Grid, And Snapping

    • Guides are editor-only alignment helpers. They do not export.
    • Select Guides, then left-drag on the canvas to draw a guide line.
    • Right-drag or middle-drag pans the canvas without leaving guide mode.
    • Choose Free line, X axis / horizontal, or Y axis / vertical for guide drawing.
    • Enable the grid when you need repeated spacing or coarse layout checks.
    • Hold Control while moving, scaling, skewing, or reshaping a vinyl layer to snap to guides or grid lines.
    • For resizing/stretching, the side you drag is the side that should snap. The opposite side stays anchored as much as possible.
    • Side handles resize one axis. Corner handles skew/disform by default. Hold Shift while dragging a corner for uniform/global scale.
    • Angled guide snapping can rotate the shape to match the guide. Horizontal/vertical guides can bring it back to straight alignment.
    • Use Clear Guides when helpers get in the way. This removes guides only, not vinyl layers.

    History, Saving, And Export

    • History lists up to 80 editable states. The loaded source is protected so Undo cannot erase it accidentally.
    • Save updates the current editable project; Save As creates another project.
    • The title shows Unsaved changes until the project and its reference image are saved successfully.
    • The recovery copy updates after edits and can be offered after a crash. It is not a replacement for Save.
    • Export Check blocks invalid transforms and reports hidden, outside-canvas, duplicate, unresolved-resource, and ineffective-mask issues.
    • Export JSON writes the portable game layer list into imgs/editor for KFPS Outputs.

    Shortcuts And Mouse Controls

    • Mouse wheel: Zoom.
    • Middle/right drag: Pan.
    • V / S / T / P / I / G / O / R: Select, Shapes, Text, Pixel, Dropper, Guides, Reference, and Move Reference. These shortcuts are ignored while typing in a text field.
    • M: Toggle selected layers as masks.
    • Drag empty canvas in Select mode: Box-select layers.
    • Hold V while dragging: Force box-select, even if the drag starts on top of a shape.
    • X / Y while dragging: Constrain selected shapes to horizontal / vertical movement, Blender-style.
    • Shift+L: Lock the current selection so accidental canvas clicks do not switch to another shape.
    • Control while dragging/editing: Snap to active guides or grid helpers.
    • Shift while dragging a corner: Uniform/global scale instead of skew.
    • Delete / Backspace: Delete selected layers.
    • Ctrl+D: Duplicate selected layers.
    • Ctrl+C / Ctrl+V: Copy and paste selected editor layers.
    • F / Shift+F: Flip selected layers vertically / horizontally.
    • Ctrl+Z / Ctrl+Y: Undo / redo.
    • Arrow keys: Nudge selection. Hold Shift for larger nudges.
    • [ / ]: Move layer order backward / forward.
    • Enter in transform fields: Apply typed position, scale, rotation, skew, or alpha values.

    Important Limits

    This is not a raster image editor. Every visible result must be represented by native shapes within the 3000-layer budget; arbitrary freehand SVG paths are not game layers.

    Keep the editable project, inspect the exported preview, and save then reopen the vinyl in game before judging a newly imported result.

    Read This Before Editing

    Most Important Limits

    • This edits FH6 vinyl JSON layers, not pixels. It is not Photoshop, Krita, or a raster image editor.
    • Reference images are saved with editable projects, but they never export into game JSON.
    • Editor groups, guide lines, grids, halos, snap overlays, and helper UI never count as vinyl layers.
    • Export one FH6 JSON, then import it through KFPS Outputs.
    • If the in-game thumbnail looks wrong after import, save and reopen the vinyl group before judging shape-library imports.
    • Recovery is a temporary safety backup in this app folder/browser. Use Save when you want a real editable project file.

    Safe Basic Workflow

    1. Open JSON or start with shapes from the library.
    2. Save early so the title can clearly track later unsaved changes.
    3. Add Reference if you want to trace or sample colors from source artwork.
    4. Edit layers: select, move, stretch, skew, rotate, recolor, group, hide, lock, duplicate, delete, and reorder.
    5. Check export readiness: confirm layer count and warnings.
    6. Export JSON and import it from Editor exports in KFPS Outputs.
