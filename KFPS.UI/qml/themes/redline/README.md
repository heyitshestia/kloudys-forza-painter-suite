# Redline

An original KFPS shell theme informed by RUINER's strong red graphic hierarchy and The Ascent's equipment-oriented interface. It uses a dedicated top navigation strip and a Create workstation: source/profile controls on the left, unfiltered artwork in the centre, source analysis and execution on the right.

The same cached pages, source queue, generation validation, budgets, checkpoints, stop actions and manual overrides remain authoritative. Switching themes preserves the underlying Create form. At compact sizes each control column scrolls independently without reducing the central artwork area to a thumbnail. Other routes retain their existing controls with Redline surfaces and typography.

Outputs puts the library first and transfer controls on the right, including at the minimum window size. Four compact category selectors call the existing folder-selection action; the file browser, menus, scans and transfers are not reimplemented. Other themes retain their existing arrangement.

Rajdhani Bold is reserved for headings and view labels; IBM Plex Sans handles body copy and IBM Plex Mono handles metadata. Fonts and Carbon icons are reused from the existing licensed asset folders. Warm white remains the main reading colour, red defines actions and selection, cyan indicates readiness and registration.

Motion consists of a short route reveal, selection-line wipes and a slow perimeter scanner. Decorations never intercept input. Ambient motion stops in inactive/minimized windows and respects both motion preferences. No shaders, media player or recurring JavaScript timers are added. The original background is a static bitmap, not a live scene. Artwork is neither tinted nor filtered.
