# Cross-Game Shape And Lettering Contract

## Scope

FH4, FH5, FH6 and FM8 share the 1,400 currently verified native vinyl slot IDs.
Their picker positions are not interchangeable with shape IDs. Binary record
layouts and group transforms still differ, so equal IDs do not imply that the
same parser grammar is valid for every game.

This contract covers local decoding, editor resource selection, preview rendering
and transfer preparation. It does not add offline FH4/FH5 import support or claim
that an untested game build has been validated. Live import/export means game
memory processing; offline import/export means local save-file processing.

## Identity Ownership

- `kfps_shapes/identity.py` owns native family bases.
- `tools/cgroup/shape_identity.py` owns conversion identity selection: full native
  numeric `type`, then explicit low-word aliases, then resource-only fallback.
  Resource labels must not change an existing numeric identity.
- Same-game raw provenance remains available for unchanged source data. Old JSONs
  whose IDs or geometry were already incorrectly rewritten cannot be reliably
  repaired from a preview. Re-export them from the original save.
- The editor and preview resolve full native types before descriptive labels.
- `shape-words.json` is generated by `tools/sync_shape_words.py`.
- `fontGlyphSlots` in `KFPS.Editor/web/editor-catalog.js` owns the per-font character
  assignments. `tools/sync_font_names.cjs` generates font display names and the
  legacy named-import registry from those assignments and the numeric catalogue.

There are 880 font slots, of which 877 have identified character aliases. Three
ornamental slots have no guessed typing alias: Upper Font 6 slot 39, Lower Font 4
slot 40, and Lower Font 5 slot 33. All remain available in the shape catalogue.
Unsupported typed characters must not silently become another letter.

Regenerate metadata after a deliberate identity or glyph change:

```powershell
python -B tools/sync_shape_words.py
node tools/sync_font_names.cjs
python -B KFPS.Editor/web/locales/manage.py build
```

CI checks generated-file freshness. The frozen mappings in the regression tests
are independent expectations, not aliases of the production mapping. Change
those expectations only with new native-game evidence, not to make a test pass.

## Parser And Renderer Rules

- FM8 first-child group transforms must not be consumed as parent inline state.
  Validate the transform and the following counted-group header together.
- A mask control before the next group belongs to the preceding direct shape,
  not to the next group or a descendant of an already closed group.
- Preserve the final shape's mask when writing a flat binary group, including
  at the 3,000-layer boundary.
- Reject nonfinite group transforms. Report unknown record bytes and incomplete
  counted groups; a plausible shape count alone is not proof of complete decoding.
- Do not paint triangles whose vertices all have zero alpha. Font meshes include
  invisible bounds geometry. The editor preserves original path bounds with
  nonpainting anchors so removing those triangles cannot move the glyph.
- Preserve partial vertex alpha in previews, including masks. Do not replace all
  alpha values with an opaque polygon approximation.

## Regression Gates

Run the normal Python tests and `node KFPS.Editor/web/tests/run-unit.cjs`.
Focused suites include `test_cross_game_shape_contract.py`,
`test_fm8_group_boundaries.py`, `test_font_import_contract.py`,
`test_json_preview_renderer.py`, `editor-catalog.node.js`, and
`editor-fonts.node.js`.

Release qualification must additionally exercise the actual managed editor:
shape creation, transformed and translucent fonts, save receipts, disk readback,
project reopen, flat export, reload, and transfer preparation for every target.
Compare both geometry and pixels. Keep private reporter artwork in ignored test
runs, never in public test fixtures.

The remaining acceptance step after local qualification is an actual FM8/FH6
import and visual/roundtrip comparison. Synthetic binary fixtures cannot prove
every native game record variant or the game's rendered result.
