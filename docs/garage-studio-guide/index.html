Garage & Livery Studio

Find your car, build a livery, and get it into FH6 as a new design. Start with the five walkthroughs below, or look up the button in front of you.

    PART 01

    Start here

    Five common jobs, from finding a car to installing a new design.

    01 / 01

    Find your car and its artwork

    There are three different starting points. Use My Cars for a body or fitted build, Saved Liveries for designs found on disk, and Packages for an editable or installable full-car file.

    1. Open Garage > My Cars. Choose your local FH6 account the first time. You can browse stock cars without one.
    2. Search the model and set Is owned if you want a particular copy. Select its square tile; check the copy number in the right-hand panel. Has livery means matching local artwork exists for the model, not necessarily that this copy is wearing it.
    3. For just the body, click Open 3D Preview or Open in Studio. For a design on the current build, select Choose local artwork, then Open Artwork in Studio.
    4. Trying to find the currently applied design? Use Show Applied Livery. It needs an exact match in scanned saves. See Scan saved liveries if nothing matches.
    Back to contents ↑

    01 / 02

    Make a new full-car livery

    A same-car package supplies the native template. Its original artwork is not a design you have to keep.

    1. Start in Garage > Packages. Select your own compatible package for the exact car and click Open in Studio. Starting Studio from the top Garage toolbar alone does not supply a full-car export template. Need a template? Export your own saved design first.
    2. Choose Save project and give this layout a new name. To start fresh, select an old placement and Remove it, or right-click a source and choose Delete vinyl source to remove its uses from the layout. For a busy template, use Placement > Select section (Ctrl+A), then Remove the selection. Repeat only on sections you want to clear. This changes the working layout, not the original package.
    3. Pick the destination Section in the top toolbar. Click Add vinyl, choose artwork, then use Move, Scale or Rotate to position it. Repeat for other sections. Click Design to see the flat section canvas.
    4. Use Save project again for your editable version. For a fitted build, save this version before restoring the stock preview. Continue with Export and install a new design.

    01 / 03

    Export a package and install it in FH6

    Studio writes a file; Garage installs it. Neither saving a project nor downloading a package puts it in the game.

    1. In Studio, keep the owned, same-car template active. Save your project. If you previewed different parts, use Car > Restore stock preview before exporting. Keep the fitted version as a separate project.
    2. Choose Project > Export livery package. Enter a Livery name and click Save package. In native Studio pick a location; in Chrome wait for the download to finish. Keep the resulting .kfpslivery intact. No ZIP steps are needed.
    3. Close FH6. In Garage > Packages > Add Package, select the file. Select the resulting entry and open Open 3D Preview so KFPS can verify it. In the preview details choose Install in FH6 Save.
    4. Read the destination account and current save folder in the confirmation. My Cars does not select the installation destination. Wrong account? Cancel, then use More > Save Folder and retry. If the destination is right, click Install and wait for the result.
    5. Start FH6, use the matching car, then open My Designs and load the new entry. Check seams and fit the intended parts in-game. The installer adds an exact-car design rather than replacing your original. Template paint is retained; custom paint or a body kit is not authored by this export.

    01 / 04

    Export a logo, one side, or the whole car

    Choose the output by what the recipient needs to do with it.

    Save project
    Use for further editing. Keeps sources, placements, sections, groups, links and part selections. Reopen with Open project. Not a game design.
    Export vinyl
    Select the source on the left. Saves its original shape artwork as a vinyl JSON; it does not bake in the placement's position, scale or rotation.
    Export section
    Select the section in the top toolbar, then Design > Export section. Produces one vinyl JSON of the visible artwork on that section with transforms baked in. Does not include other sections or a car body.
    Export livery package
    In Project, creates a full-car .kfpslivery for Garage. Requires a compatible owned template for the same car. Not a Studio project or an automatic installation.
    Export experiment / Export ZIP
    Diagnostic native candidate and layout for isolated testing. Confirm or Cancel. It is not the Garage share package: do not rename a ZIP to .kfpslivery.

    01 / 05

    Match an owned build without losing the original

    Previewing the right body helps align artwork. The body you see and the artwork file you export are separate.

    1. Choose the exact owned copy in My Cars. To combine that copy's parts with art, choose compatible local artwork and click Open Artwork in Studio. A bare Open in Studio from My Cars loads no artwork.
    2. In Studio's Car tab compare the kit, bumpers, hood, skirts and wing to the real car. In View, inspect the intended section. Save a named project for the fitted version.
    3. Export the artwork against the stock preview, then fit the parts in FH6. Do not use the part list as a purchase list: model support, names and paintability vary. See the part controls and compare two owned copies.

    PART 02

    Garage

    Accounts, the car catalogue, saved designs and packages.

    02 / 01

    Connect the right install, save folder and account

    Three choices do different jobs. The game folder supplies models, the save folder supplies saved designs and the installation destination, and the My Cars account supplies ownership and fitted parts.

    More
    Opens Garage’s local file, cache and diagnostic actions. It does not open the car inspector.
    Link FH6 Folder / Change FH6 Folder
    Select the installed game or Content folder, not a save or a Studio project. With two installs, choose the updated one; their catalogues are not combined.
    Save Folder
    Choose the FH6 GameSave root for saved liveries. Check the resolved account again in the install confirmation; selecting a driver in My Cars does not change this destination.
    Choose an account
    Under My Cars, choose a discovered local profile. This choice is remembered. Use the same dropdown to switch. A name is shown only when it can be identified reliably.
    Rescan FH6 accounts
    Use the small circular-arrow button next to the account field to refresh the list of local accounts. An unavailable old account is not a substitute for a new one.
    Choose File
    Use the manual Garage source picker when detection cannot find the intended Garage file. This selects ownership/build data; it does not import a livery package.
    Cancel (Garage read)
    While Garage is reading, stop that operation instead of changing sources underneath it. Wait until controls are available before retrying.
    Refresh (My Cars)
    Recheck the Garage and installed catalogue. For a missing new car, check the linked installation before refreshing. Browsing reuses valid cached data.
    Open Package Folder
    Opens the managed local package folder in Explorer. Use Add Package in the UI when bringing in a file from elsewhere.
    Clear Cache
    Clear generated livery preview cache if a preview stays stale. The next preview can take longer; this is not a way to remove an owned design.
    Diagnostics
    Exports local livery diagnostics for troubleshooting. Review the files before sharing them.
    Manual (Garage)
    In the Garage header, next to Studio, open the Garage chapter in your default browser. You do not need to select an account, a car or a package first.

    02 / 02

    Browse the catalogue, owned copies and fitted art

    Open Garage > My Cars. The left grid identifies the model or owned copy, not necessarily the artwork on it. The right column follows the selected tile.

    My Cars
    Use this tab for stock catalogue entries, owned copies, fitted parts and comparisons. A stock thumbnail is normal even when a livery is available.
    Search cars, copies or saved liveries
    Enter a model name, copy or matching livery information. If an expected car disappears, clear the search and check the active filter.
    All cars / Is owned / Duplicate models / Has livery
    All cars includes catalogue-only entries; Is owned shows the chosen account’s copies. Duplicate models narrows to repeated owned models. Has livery finds cars with matching locally available art, not necessarily an exact applied design or your authorship.
    Manufacturer: A to Z / Is owned first / Has livery first
    Sorting changes order; it does not restrict the results like the filter does. The view choice is remembered.
    Car tile
    Click to select; use arrow keys to move, Home or End for the ends. Model ID identifies the car model; copy ID distinguishes owned instances. No stock image means artwork was unavailable, not that the car is missing.
    Open 3D Preview (My Cars)
    Inspect the selected body, without a livery. An owned copy supplies fitted options; a catalogue-only entry uses stock defaults.
    Open in Studio (My Cars)
    Starts an editable layout for the selected body. Seeing a bare car here is expected. To start with art, use the artwork picker instead.
    Choose local artwork / Open Artwork in Studio
    Select compatible local artwork from the dropdown on an owned copy, then click Open Artwork in Studio. Combines that artwork with the current body, not necessarily the body on the day the design was saved.
    Show Applied Livery
    Opens the exact referenced livery in Saved Liveries if KFPS can match it. This is stricter than Has livery; scan saves if there is no match.
    Saved part IDs
    Expand to inspect recorded options. Kits, chassis/cage, bumpers, hood, skirts and wing can be represented. Generic labels are possible. This list does not install upgrades or resolve wheels and tyres.

    02 / 03

    Compare builds and link a Studio project

    Select an owned copy. Scroll its right-hand details column below the build actions. A comparison stores a local reference; it is not a tuning file.

    1. Select the starting copy and click Compare From Here. Select the second copy or inspect a later reading. The list shows changed fields and their before/after IDs; no differences means the compared fields match.
    2. To retain a reference, choose Save Comparison, give it a memorable name and accept. Select it later in Choose comparison. Two copies with the same car ID can have different part IDs.
    3. With a saved comparison selected, use Link Studio Project to attach a same-car project. Use Check Project before opening a link that may have moved.
    Compare From Here / Clear
    Pin the current baseline, or clear the active comparison. Clear is not the Remove command for a saved note.
    Choose comparison / Save Comparison
    Recall a named comparison or save the current snapshot locally. Cancel the naming dialog to leave it unsaved.
    Remove (comparison)
    Removes the selected comparison and its link only after confirmation. Cancel keeps both; the linked project file is not deleted.
    Link Studio Project / Relink Studio Project
    Pick a matching saved Studio project. Relink when the original path or intended project changes.
    Check Project / Show Folder
    Validate the current link, or open its containing folder to locate the file. Neither action opens or modifies artwork.
    Open Linked Project
    Open the linked project with its authoring data in Studio, detached from the original file. Saving edits is explicit.
    Keep local change history
    Available only when the source has a verifiable continuous identity. Snapshot-only native Garage data cannot promise automatic history. Use named comparisons instead.
    Comparison name / Save / OK
    In Save Comparison enter a name and choose Save. In Remove Saved Comparison? choose OK only to remove that saved note and its link, not the Studio project. Cancel leaves the existing state.

    02 / 04

    Scan saved liveries and create a template

    Saved Liveries lists designs found in the selected FH6 save location. Selecting one is not the same as importing, editing or installing it.

    1. Use More > Link FH6 Folder for the matching game install and More > Save Folder for the save root. Open Saved Liveries and select Scan Saves.
    2. Single-click a design. Check its car ID, count and source availability on the right. Double-click or press Enter on a row/tile to open its preview.
    3. For your own eligible save, use Export Selected to create a verified package. Switch to Packages, select it and use Open in Studio. Browsing or previewing someone else’s art does not grant export permission.
    Saved Liveries / Scan Saves
    Browse or rescan local FH6 livery sources. Scan Saves is not the My Cars Refresh and does not create an in-game entry.
    Search saved liveries / All cars (saved designs)
    Narrow by text and exact car ID. Use the reset icon to clear filters if a known design is absent.
    All availability / Exportable / Preview only
    Select Exportable to find sources that can become packages. Preview-only means the source cannot be exported via this action; inspect its privacy and availability details.
    Newest first / Title / Car ID / Most shapes
    Order the saved-library results. Modified time belongs to the source; shape count is not the number of cars.
    Clear search and filters
    The small reset icon next to the sort clears the Saved Liveries browser filters; it does not erase designs.
    Source details / Export Selected
    Check Modified, Header and Availability. Export Selected creates a shareable package when allowed; vehicle meshes stay local. It does not change the source save.
    Open 3D Preview (saved design)
    With the game folder linked, open the selected saved design on its exact car. There is no Open in Studio button on raw saves: export an eligible design to Packages first.

    02 / 05

    Add, browse and open a livery package

    A .kfpslivery is a full-car package. A vinyl JSON, a Studio project and an experimental ZIP are not interchangeable with it.

    Packages / Add Package
    Open Packages, click Add Package and choose the intact .kfpslivery. Wait for the result. If it fails, read Package not added; do not unzip it or change another file’s extension.
    Search packages, models or IDs / All cars (packages)
    Search package titles or model identifiers; choose a car to narrow to its ID. Select the reset icon to clear search and filters.
    Title / Car ID / Most shapes (packages)
    Sort the local package list. The visible/total counter helps distinguish a filter from a missing entry.
    Package row / Package details
    Single-click to inspect. Created, Portable mesh and Verification describe the file. Pending open means the list entry has not been verified by opening it; Not included for mesh normally means the local game model is used.
    Open 3D Preview (package)
    Verify and preview the selected package. Double-click or Enter on the row also opens the preview. Use this route before installing.
    Open in Studio (package)
    Opens that package’s compatible artwork on its car. This is not the bare-car button in My Cars. A managed owned same-car package can act as a Studio export template. In a separately opened Chrome Studio session, choose the matching car first if prompted, then retry the handoff.
    Studio (Garage toolbar)
    Launch Studio directly without a selected package handoff. Use this for browsing or section work; use the package row action when you want its artwork or template.
    Clear package search and car filter
    The reset icon beside sorting clears the search and car filter, not the package or its verification state.

    02 / 06

    Inspect a read-only 3D preview

    Use Garage Preview to inspect an existing design; choose Studio to edit. Read the selected car and counts first. Some geometry, materials, reflections and wheels only approximate FH6.

    Preview / Details / Close details
    In compact Garage layouts use Preview to open the selection and Details to open its separate inspector. Close details returns to the underlying view; opening details does not install anything.
    Standard / High
    Set Garage viewer vinyl detail. High asks for finer textures at extra load; resource limits can cause fallback. This does not add shapes or alter the save. Studio has separate Fast/Balanced/Sharp settings.
    Reset view / Auto rotate
    In the 3D view, use the framing icon to fit the car and the rotation icon to start or stop camera rotation. Drag to orbit and use the wheel to zoom.
    All / Top / Left / Right / Front / Back
    Use the strip to inspect the whole car or a particular side. These preview controls do not reassign artwork to another section.
    Preview details / Placeholder wheels
    Open the viewer details to inspect fidelity and fitment. Toggle stand-in wheels where available; this is a display aid, not an installed wheel choice.
    Geometry / Materials / Warnings
    Scroll the inspector to read the available evidence. Check quality scale, paint and mask atlas size, mesh cache and limitations before treating a missing panel or odd finish as missing artwork. These are information headings; Compatibility is the expandable control.
    Livery sections / Preview slots / Compatibility
    Read section counts and available slot data. Expand Compatibility for the target decisions and their reasons; a rendered preview alone does not prove the design can be installed.
    Retry Preview / Back to Garage / Back to Liveries
    Retry after fixing a missing folder, model, cache or temporary problem. Back returns to the originating browser without discarding the source.
    Install in FH6 Save / Install / Cancel
    Available on an eligible verified package in preview, not a bare stock body. Check the account in the confirmation, not just the My Cars dropdown. See the complete install steps.

    PART 03

    Livery Studio

    Authoring controls, projects, preview and recovery.

    03 / 01

    Find your way around Studio

    Start with the car in the centre. The left column holds the artwork; the right column changes with the selected inspector tab. The label above the car identifies the model you are actually editing.

    1. Use Choose car for a different local model. To edit an existing Garage package with its template attached, open the package from Garage instead.
    2. For a quick introduction choose Tour. To find one particular tool choose the magnifying glass (Search commands) and type its name.
    Choose car / Search cars / Open car
    Search by name, model code or car ID, select a result and choose Open car. Give the new car time to prepare. Close exits the picker; Cancel preparation stops a pending switch; Retry status checks an interrupted preparation.
    Save and switch / Discard and switch / Cancel / Cancel preparation / Retry status
    Layouts belong to a car. Save and switch keeps the current layout in its car’s folder; Discard and switch drops unsaved edits. Cancel stays on the current car.
    Placement / Design / Car / View / Project
    Placement: transforms, groups and alignment. Design: section canvas, colour, opposing sides and Editor. Car: components. View: surface inspection, display and language. Project: recovery, template and exports. Scroll inside the inspector for lower controls.
    Orbit / Reset view / Auto rotate
    Press O or click Orbit to drag the camera without moving vinyls. Scroll to zoom. Reset view fits the visible model; Auto rotate spins or stops the view. Neither edits the project.
    All / Top / Left / Right / Front / Back
    The strip below the 3D model controls what you inspect. Availability depends on the model and prepared sections. Use Placement section, not this strip, to move an existing item.
    Search commands
    Click the magnifier, type part of a command name and choose a result. A command that needs a template, selection or placement is not an alternative way around that requirement. For example, “Export source artwork”, “Export section artwork” and “Export experimental ZIP” lead to three different outputs.
    Tour / Next / Previous step / Close tour / Done
    Read one highlighted area at a time. Next advances; Previous step goes back. Close tour or Escape exits early; finish the last step to dismiss it. You can start again without changing your layout.
    Manual (Studio)
    Beside Tour in the top toolbar. Opens this manual at the Livery Studio chapter in your default browser, leaving the current project in Studio. Tour is the separate in-app walkthrough.

    03 / 02

    Add artwork and reuse a vinyl

    A source is the collection of shapes; a placement is one use of it on the car. You can place one source several times without importing the file again.

    1. Set Section on the toolbar, then Artwork > Add vinyl. Pick a generated or native vinyl JSON. Adding it also places the first copy on the active section.
    2. To put the same artwork elsewhere, choose the next section, select the existing Vinyl source, then click Place vinyl. Move that copy where you want it.
    3. To remove just one use, select its placement and use Remove. To remove the source and all its placements, use the source’s context menu and read the count before confirming.
    Add vinyl / Add selected vinyl
    Browse the vinyl library. Open a folder or select a file, then Add selected vinyl. A picture file or full-car .kfpslivery is not a vinyl JSON.
    Up one folder / Load more / Browse elsewhere... / Cancel
    Go up a folder, fetch more entries, use the file picker outside the library, or leave without adding anything.
    Vinyl sources / Vinyl source / Place vinyl
    Choose the source by name or from its list. The small preview is the original source artwork. Place vinyl adds an instance at the centre of the active section.
    Placements
    Click a placement row to select its instance on the car. A source row and a placement row are different: use the latter for transforms, ordering or editing.
    Export vinyl
    Writes the selected source’s original shapes. For a positioned, scaled or combined design on one side, use Export section instead.
    Delete vinyl source / Delete
    Right-click the source row (or focus it and use the context-menu key or Shift+F10). Read the confirmation, then Delete or Cancel. This removes its uses from the layout, not the original JSON on disk. Unlock affected placements if blocked; Undo restores the layout change.

    03 / 03

    Move, resize and order a placement

    Select the vinyl on the car or click its row in Placements. In Placement, the numbers describe the selected instance, not every copy of that source.

    1. For a rough fit choose Move, Scale, Rotate or Skew and drag on the car. Releasing the pointer commits a normal drag. While a transform is pending, Enter accepts it and Escape cancels it.
    2. For an exact fit use the numeric fields. To move a low-contrast or overlapping logo, select it in the list first. Use the Design > Section canvas for flat positioning instead of trying to grab a narrow panel in 3D.
    Move / Scale / Rotate / Skew
    V moves; S resizes; R rotates; K shears. These are artwork modes; switch back to O for camera orbit. Apply (Enter) commits a pending transform; Cancel (Escape) does not.
    Section / Placement section
    Toolbar Section sets the active authoring surface for new work and section output. Placement section reassigns the selected instance to an eligible surface, retaining its transform. Check the new projection.
    X / Y
    Position from -4096 to 4096. Positive X moves right; positive Y moves up in section coordinates. The camera angle can make this look different in 3D. Use a slider for a visual adjustment or type the exact value in its field.
    Scale X / Scale Y / Lock aspect ratio
    Scale multipliers run from 0.01 to 8; 1 is original size. Lock aspect ratio before changing one dimension to preserve the current proportions.
    Rotation (deg) / Skew value
    Positive rotations are counterclockwise; use degrees (-3600 to 3600). Numeric Skew is horizontal shear (-4 to 4), not an angle; 0 means no shear.
    Opacity / Opacity slider / Visible
    0 is transparent, 1 fully opaque. Toggle Visible to hide without deleting. Some translucent multi-shape results cannot be written exactly into a game vinyl; see export checks.
    Duplicate / Move backward / Move forward / Remove
    Duplicate (Ctrl+D) adds a copy. The arrows move an item behind the preceding or ahead of the following placement on this section. Remove (Delete) removes the placement. Undo reverses it.
    Undo / Redo
    Undo the last layout edit with Ctrl+Z. Redo with Ctrl+Y or Ctrl+Shift+Z. For a version that survives closing, use Save project or a named checkpoint.
    Apply / Cancel transform
    Accept the live transform using Enter, or discard it using Escape. Finish this operation before switching tools, opening a dialog or saving.

    03 / 04

    Select, group, align and space artwork

    For a row of sponsors, place the logos on the same section first. Arrange the outer two, select all the logos, then align and distribute them.

    Select section / Clear
    Select all placements on the current section (Ctrl+A), or clear the selection without removing artwork. Shift-click artwork or Ctrl-click placement rows to add to a selection.
    Artwork under pointer
    Alt-click the car or flat section canvas where items overlap. Pick one result in the stack, or Close. Alt-click a placement row to select just one member of a group.
    Group name / Group / Ungroup
    Select the intended placements, optionally enter a name, then Group (Ctrl+G) to manipulate them together. Ungroup (Ctrl+Shift+G) preserves their positions.
    Lock / Unlock
    Select a finished item or group and Lock it to protect it from accidental edits. Select its row and Unlock before changing it. A locked member can block a multi-item operation.
    Alignment / Align
    Choose Left edges, Horizontal centres, Right edges, Top edges, Vertical centres or Bottom edges, then Align. Select at least two unlocked units on one section. Groups count as units.
    Space horizontally / Space vertically
    Select at least three independently movable units on one section. The two outer units set the range; space the intermediate units by their edge gaps.
    Snap to centres and artwork
    Turn on snapping for centre and edge guides while dragging. Hold Ctrl during the drag to bypass it temporarily.
    Nudge selection
    Focus the section canvas and use arrow keys to move one unit. Hold Shift with an arrow to move ten. Escape cancels a drag.

    03 / 05

    Check the flat canvas and use masks

    Use the flat view when the car’s curvature makes it hard to judge an edge. It shows the layout for one section, not a promise that every pixel maps onto paintable bodywork.

    1. Choose the Section in the top toolbar. Open Design > Section canvas. Select or drag an item on the flat canvas; inspect the result on the car.
    2. A native mask cuts away paint drawn earlier on that section. Check placement order when a cutout seems to do nothing. A patch the colour of the car is paint, not a transparent hole.
    3. Read the shape count and the separate full-livery section cap. Export section saves visible artwork on this section as one native vinyl JSON, not a new full-car design.
    Section canvas
    Drag to move, Alt-click to choose overlapping artwork, or use arrow keys for fine positioning. Switch to another section to see its own canvas and counts.
    Source shapes / vinyl export limit
    Visible placements contribute their source shapes, including repeated sources and masks. Zero-opacity placements do not contribute. The standalone section vinyl limit is 3,000 shapes.
    Livery section cap
    Full-car output uses a separate cap, which may be lower. Read the displayed cap for the active section instead of assuming the standalone limit applies everywhere.
    Export section
    Bakes placement transforms into a new JSON. If Studio rejects the result, the original project remains editable. A mask-only section can be meaningful; inspect it together with the paint it is intended to cut.
    Back to contents ↑

    03 / 06

    Change an artwork colour, not the car paint

    Use Design colours to change the paint in your vinyl shapes. It is not a car-body or material editor.

    1. Open Design > Design colours. Set Apply to before choosing an existing swatch. Choose Replacement colour, then Replace colour.
    2. Read the affected scope, confirm, and inspect another copy of the artwork before saving. Use Undo if you meant to change a smaller selection.
    Apply to / Selected placements / Whole design
    Selected placements limits the change to selected uses. Whole design looks for this shape colour throughout the layout. Unlock artwork that must change; mask shapes are not colour swatches.
    Artwork colours / Replacement colour / Replace colour
    The source swatches represent colours already used; their tooltips show colour and shape count. Pick one, choose the new colour, then click Replace colour. Choosing the colour alone does not apply it.

    03 / 07

    Copy a design to the other side and link it

    Create the opposite side first; link only after you have aligned it. Door shapes and side coordinates are not guaranteed to match.

    1. Select one unlocked placement on an eligible left or right body or window section. Choose Artwork orientation, then Create other side.
    2. Check the new side on the car and move it where it belongs. Select the two opposing placements and use Link aligned pair. The active placement supplies the artwork; the partner keeps its aligned pose.
    3. Test with one small move and inspect the opposite side. If the pair should diverge, choose Unlink before editing them independently.
    Readable lettering / Mirrored artwork
    Readable lettering is for text that should read normally on both sides. Mirrored artwork reflects the source shapes; useful for directional graphics.
    Create other side
    Makes an opposite-side placement. This does not prove correct physical alignment or link the pair automatically.
    Link aligned pair / Update orientation / Unlink
    Link uses the two poses you established; it can replace the partner’s artwork. Update orientation changes the mode of an existing link. Unlink disconnects the pair without removing the placements.

    03 / 08

    Edit individual shapes in the 2D Editor

    Studio places vinyls on a car. Use the 2D Editor when you need to change what is inside a vinyl rather than where it sits.

    1. Select exactly one unlocked placement and open Design > Edit source artwork > Edit vinyl. Work on the source in the Editor and click Return to Studio when done.
    2. Back in Studio choose Check changes. Set Returned artwork to the intended scope, then Apply returned artwork. A file saved in the Editor is not by itself an applied change in Studio.
    3. Inspect the edited placement and another use of the same source. Save the Studio project to retain the result.
    Edit vinyl
    Starts a linked source-edit session in supported hosts. If unavailable, check selection, lock state and whether another edit is pending. It is not an editor for the entire car in one 2D canvas.
    Return to Studio (2D Editor)
    When a linked vinyl is open, use this Editor button to return the source. Back in Studio, confirm the scope and explicitly apply it.
    Check changes
    Refreshes the status of the active edit link. If nothing has returned, finish the Editor return step rather than opening a second link.

    PART 04

    Troubleshooting

    Use the symptom to find the right check.

    04 / 01

    Find out why an action is missing or disabled

    Start with what you expected to change: the view, the layout, a package on disk, or a design in the game. Each has a different check.

    A newly added car is missing
    Check More > Change FH6 Folder points to the updated installation, not an older Steam or Xbox copy. In My Cars use Refresh, clear filters and search by model code or ID. The account determines ownership, not the entire stock catalogue.
    The car opens but no artwork appears
    From My Cars, Open in Studio deliberately opens the body only. Choose local artwork and use Open Artwork in Studio, or open the actual entry from Packages. If the package itself fails, read verification and compatibility before retrying.
    A tool is grey
    Select the right item: a placement for transforms, one unlocked placement for Edit vinyl, two compatible placements for linking, or an eligible template for full-car export. Finish a pending drag or close the current dialog.
    My colour or mask looks wrong
    Turn inspection Off, check visibility and layer order on the same section, and use full opacity for masked placement export. A later shape can cover a cutout. Increase preview quality before adding shapes to compensate for a soft edge.
    The export rejects my design
    Check the exact section cap, masks, zero-opacity or hidden items and geometry extending past the source canvas. Reframe clipped shapes in the 2D Editor. Keep masked placements at 100% opacity; grouped translucency and unsupported raster/opaque records can prevent an exact export. Keep a named project before simplifying.
    The file saved but I cannot see it in FH6
    Check the extension: .kfps-layout.json and a vinyl JSON are not full-car packages. A .kfpslivery must be added and installed in Garage. Verify the destination account and car ID, restart FH6 to reload the save, and check My Designs for the same car. Don’t delete or overwrite an existing design to test.
    A wing is missing or paint stops at a seam
    Compare the exact owned copy, kit, selected section and mapping in View. Check for missing geometry and real paint eligibility in FH6 with the intended parts fitted. Saving or installing artwork does not purchase parts or author custom paint.
    I need to report a mismatch
    Note the KFPS build, car ID, body/wing selectors, section, whether you used Preview or Studio, exact failing action and message. Include matched Studio and game views if available. Keep any personal account and local folder details private.
