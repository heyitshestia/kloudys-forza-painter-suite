# Studio Vinyl Preview Quality

Use **Vinyl preview quality** in the Studio toolbar to choose the resolution of
the vinyl previews:

| Setting | Vinyl/section resolution | Intended use |
| --- | --- | --- |
| Fast | 1024 x 512 | Lighter previews while editing |
| Balanced | 2048 x 1024 | Default; matches the previous resolution |
| Sharp | 4096 x 2048 | Inspect finer vinyl details; uses more memory |

The choice is shared by the native Studio window and Chrome and remembered on
restart. English, Korean and Japanese labels use the existing localization and
theme systems.

This is a preview setting, not an artwork conversion. Previews are rendered from
the original shapes at the selected size. Source geometry, whole-vinyl picking,
placement, UV coordinates, project files and exports keep their original values.
The read-only livery viewer is unchanged.

Studio checks texture limits and estimated memory before switching. It accounts
for both the old and replacement previews while changing quality. A failed
render keeps the previous working preview. If a preference cannot be saved,
the current session remains usable and Studio reports the problem. Unsupported
saved choices receive an explicit fallback without overwriting the preference.
Preferences are stored in `tools/livery-studio/settings/preview-quality.json`;
the normal updater preserves this folder.

## Validation

Regression coverage includes dimensions, original renderer pixels, masks,
clipping, picking bounds, strict request validation, preference persistence,
interrupted writes, invalid files, switching failures and resource disposal.
Synthetic stress inputs are generated by the tests; no personal artwork or game
assets are included. Windows CI runs the backend and frontend regression tests.

Headless Windows checks also exercised native Studio and Chrome with up to 3,000
shapes, repeated quality changes, transforms, undo/redo, save/reopen, translations
and compact/wide layouts while monitoring GPU usage. This is not qualification
of every graphics adapter or physical display-scaling combination.

Studio's experimental game-save export and per-car paintability limitations are
unchanged. Preview quality does not certify in-game export compatibility.
